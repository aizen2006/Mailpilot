# Stitch Mockup Prompt (Sidebar Showcase)

Use this prompt directly in Stitch to generate the single showcase mockup for MailPilot sidebar chat.

## Prompt

Design a high-fidelity Chrome extension sidebar UI for an AI email assistant named MailPilot.

Layout and proportions:
- Vertical side panel, desktop browser context, about 380px width and tall viewport.
- Modern, clean, premium product feel with clear hierarchy and compact-but-breathable spacing.
- Background: very light neutral surface with elevated card layers and subtle shadows.

Top section:
- Header title: "MailPilot".
- Gmail status pill below title: "Connected as name@company.com".
- Right utility controls: profile icon button, settings icon button, close icon button.
- Under header, include three context chips: "History", "Agent mode", "Connections".
- Add micro copy under chips: "Connect Gmail, Calendar, Slack and more."

Main conversation section:
- Distinct rounded conversation well with subtle border and softened elevated background.
- Show 4 chat messages with realistic spacing:
  - 2 assistant messages in light bubbles.
  - 2 user messages in teal-accent bubbles aligned to the right.
- One assistant bubble should contain a compact email draft snippet.
- Keep text readable, avoid visual clutter.

Composer section (bottom):
- Label: "Ask MailPilot".
- Tone chips: "Professional" (active), "Concise", "Quick reply".
- Multiline input (4 rows) with placeholder:
  "Summarize this thread, draft a reply, or ask for next steps…"
- Action row:
  - Left: small square attach button with "+".
  - Right: mic button and a primary "Send" button.
- Footer helper text:
  - Left: "Ctrl Enter to send"
  - Right: "Modes: Attach file, Thinking, Better model"

Visual language:
- Shadcn-inspired component styling and semantic UI structure.
- Crisp typography, high contrast, no noisy gradients.
- Subtle polish cues: precise paddings, balanced icon density, clear CTA prominence.
- Keep motion implied (micro-interaction quality), but this is a static mockup.

Constraints:
- Do not include browser chrome or unrelated app screens.
- Do not copy other products exactly.
- Produce one polished showcase frame only.
